# Zackophony

Soundboard overlay app made for my friend zack LOL

## Prerequisites

Currently only supports Windows.

## Installation

### Prebuilt Binary

You can install Zackophony by downloading [the installer bundle](https://github.com/vi013t/zackophony/tree/main/crates/zackophony-installer/Zackophony) and running the installer from there. The **entire folder** (including `App/` and `Resources/`) is required for the installation. The installer will automatically install the VB Virtual Cable drivers necessary to use the soundboard, register a start menu shortcut, and enable the soundboard as a startup task.

### Building From Source

You can build [the installer](https://github.com/vi013t/zackophony/tree/main/crates/zackophony-installer) from source with `make build`. The installer will automatically install the VB Virtual Cable drivers necessary to use the soundboard, register a start menu shortcut, and enable the soundboard as a startup task.

## Usage

The default hotkey to open the soundboard is ``Shift + ` ``. The hotkey (and other settings) can be changed in the settings through the gear button in the lower left.
